# 🍀 Clo-ver (의류 전문 중고 거래 플랫폼)

**Clo-ver**는 기존 범용 중고거래 플랫폼의 한계를 넘어, 의류의 물리적 특성을 세밀하게 반영한 데이터 구조와 사용자 경험을 제공하는 **패션 특화 중고거래 모바일 플랫폼**
입니다.

---

## 👨‍👩‍👧‍👦 팀 소개 (4조 - 옷정리하조)

프로젝트의 효율적인 진행을 위해 다음과 같이 역할을 분담하여 협업하고 있습니다.

* **이은아 (조장)**: 프로젝트 총괄, 프론트엔드 총괄 및 최종 검토
* **김수형 (기술 리더)**: 깃(Git) 관리자 및 백엔드 개발
* **이지온 (PM)**: 프로젝트 매니저, 백엔드 개발 및 요구사항 정의
* **이승준 (백엔드 총괄)**: 백엔드 서버 구축 및 API 개발 총괄
* **이성은 (DB 관리자)**: 데이터베이스 물리 스키마 설계 및 ERD 작성
* **임하영 (문서 관리)**: 프론트엔드 디자인 초안 및 프로젝트 산출물 관리
* **안연수 (문서 관리)**: 프론트엔드 담당 및 발표 자료 구성
* **김태현 (프론트엔드)**: UI/UX 설계 및 핵심 컴포넌트 개발

---

## 🚀 프로젝트 목표 및 필요성

* **의류 특화 시스템**: 브랜드, 상세 사이즈, 상세 핏 등 패션에 최적화된 데이터베이스 구축
* **사이즈 문제 해결**: 사이즈 미스로 인한 재거래 및 동일 상품 타 사이즈 사용자 간 매칭 지원
* **커뮤니티 통합**: 단순 거래를 넘어 코디 추천 및 패션 정보 공유가 가능한 소통 공간 마련
* **ESG 가치 실현**: 의류 재사용을 통한 탄소 절감량을 수치화하고 보상을 제공하는 시스템 도입

---

## ✨ 핵심 기능 (Key Features)

### 1. 지능형 의류 탐색 및 추천

* **핏(Fit) 기반 추천**: 사용자의 체형 정보 및 취향 분석을 통한 개인화 상품 제안
* **정밀 필터링**: 브랜드, 스타일, 상세 실측 데이터를 기반으로 한 카테고리별 필터 제공

### 2. 거래 관리 및 안전 시스템

* **실시간 채팅**: 구매자와 판매자 간의 1:1 메시지 및 거래 상태(예약/완료) 관리
* **신뢰도 관리**: 본인 인증 절차 및 거래 후기를 통한 매너 점수 시스템

### 3. 패션 커뮤니티

* **스타일 공유**: 유저들의 코디 리뷰 등록 및 좋아요/댓글 등 상호작용
* **정보 게시판**: 자유/후기/스타일/정보 공유 등 4대 게시판 운영

### 4. 에코 보상 시스템

* **탄소 발자국 계산**: 거래 완료 시 의류 재사용에 따른 탄소 배출 절감량 자동 계산
* **에코 포인트**: 환경 기여도에 따라 플랫폼 내에서 활용 가능한 포인트 지급

## 🏗 시스템 구조 (Architecture)

본 시스템은 클라이언트 앱과 백엔드 서버 간의 **REST API (JSON)** 통신을 기반으로 동작합니다.

* **Client**: UI Manager 및 API ServiceRequester를 통한 사용자 요청 처리
* **Server**: Request Controller와 Transaction/SalePost Service를 통한 비즈니스 로직 수행
* **Storage**: 고해상도 이미지는 별도의 Cloud Storage에 보관하여 DB 부하 최적화
